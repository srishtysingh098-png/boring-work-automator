# 🤖 Boring Work Automator

A simple Python automation project that reduces repetitive daily computer tasks.

## 📌 Problem

We often spend time doing repetitive tasks such as:

- Organizing files
- Renaming multiple files
- Checking how many files are in a folder
- Creating folders manually

These tasks are simple but time-consuming.

## 💡 Solution

Boring Work Automator is a Python-based tool that automates these tasks from one simple menu.

## ✨ Features

### 📁 File Organizer
Automatically organizes files into categories such as:

- Images
- PDFs
- Documents
- Videos
- Audio
- Excel files

### ✏️ Bulk File Renamer
Rename multiple files automatically using a common name and numbering system.

### 📊 File Report Generator
Generate a quick report showing:

- Total number of files
- File extensions
- Number of files of each type

## 🛠️ Technologies Used

- Python
- OS module
- Shutil module
- Collections module
